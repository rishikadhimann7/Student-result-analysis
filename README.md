# Student Performance Analysis 📊

## About the Project

This is my first Python data analysis project, where I explored student performance data to understand how different demographic and family-related factors relate to students' academic scores.

The project uses Python, Pandas, Matplotlib, and Seaborn to clean, analyze, and visualize data, with a focus on Math, Reading, and Writing scores.

## Objectives

- Explore and understand the student dataset.
- Identify and inspect missing values.
- Generate descriptive statistics.
- Analyze the distribution of students by gender.
- Compare students' scores across different parental education levels.
- Explore the relationship between parental marital status and academic performance.
- Visualize patterns in the data using charts and heatmaps.

## Technologies Used

- **Python** — programming language
- **Pandas** — data manipulation and analysis
- **NumPy** — numerical computing
- **Matplotlib** — data visualization
- **Seaborn** — statistical visualization
- **Jupyter Notebook** — interactive development environment

## Dataset

The project uses a student performance dataset containing demographic information, family-related features, and Math, Reading, and Writing scores.

The dataset includes columns such as:
- Gender
- Ethnic Group
- Parent Education
- Lunch Type
- Test Preparation
- Parent Marital Status
- Practice Sport
- Number of Siblings
- Math Score
- Reading Score
- Writing Score

## Project Workflow

1. Imported the required Python libraries.
2. Loaded the dataset using Pandas.
3. Inspected the first few rows and dataset structure.
4. Generated descriptive statistics using `describe()`.
5. Checked data types and missing values.
6. Removed an unnecessary index column.
7. Analyzed student gender distribution.
8. Compared academic scores across parental education groups.
9. Created visualizations, including bar charts and heatmaps.
10. Interpreted patterns observed in the data.

## Key Insights

- The dataset contains students from different demographic and family backgrounds.
- Students' Math, Reading, and Writing scores can be compared across parental education categories.
- Visualizations help reveal patterns and differences in academic performance.
- The analysis explores associations between family-related factors and scores; it does not establish that these factors cause differences in performance.

## How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd YOUR_REPOSITORY_NAME
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run the notebook

Open the `.ipynb` file and execute the cells from top to bottom.

Make sure the dataset file is available at the path expected by the notebook.
